# CodSoft Data Analytics Internship

## Project Overview
This repository contains my work completed as part of the CodSoft Data Analytics Internship.

The project focuses on data cleaning, exploratory data analysis, and data visualization using Python.

## Tasks Completed

### Task 1 – Data Cleaning and Preprocessing
- Identified missing values.
- Removed duplicate records.
- Handled missing and invalid values.
- Standardized text data.
- Converted columns into appropriate data types.
- Created a Sales column.

### Task 2 – Exploratory Data Analysis (EDA)
- Generated descriptive statistics.
- Analyzed sales by city.
- Analyzed sales by product.
- Examined product quantities.
- Analyzed daily sales trends.
- Detected outliers using the IQR method.

### Task 3 – Data Visualization
Created the following visualizations using Matplotlib:
- Bar Chart – Total Sales by City
- Line Chart – Daily Sales Trend
- Histogram – Sales Distribution
- Scatter Plot – Quantity vs Sales
- Pie Chart – Product-wise Sales Distribution

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
The project uses a sample sales dataset containing order details, dates, customers, products, quantities, prices, and cities.
